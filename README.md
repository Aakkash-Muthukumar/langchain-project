# Example LangChain Project

This is a sample project demonstrating a multi-agent system for customer support automation.

## Agents

1. **Triage Agent** - Routes customer queries to appropriate specialists
2. **Technical Support Agent** - Handles technical issues
3. **Billing Agent** - Manages billing and payment queries
4. **Escalation Agent** - Handles complex cases requiring human intervention

## Tools

- Email sending
- Database queries
- Knowledge base search
- Ticket creation

## Usage

This is a demonstration project for testing the AI Agent Testing Framework.
